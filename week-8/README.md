# Food Delivery System - Backend Receipt Generator

## Purpose of the application
This application is a receipt generator for a Food Delivery System. It takes user input for an order, calculates the subtotal, adds a 5% service charge, applies a delivery fee if requested, and generates a formatted receipt. 

## Tech Stack
* **Language:** Python 3
* **Environment:** Terminal / Command Line Interface (CLI)

## How to use
1. Ensure you have Python installed on your machine.
2. Clone this repository or download the files (`main.py`, `customer.py`, `receipt.py`) into the same directory.
3. Open your terminal or command prompt and navigate to the directory containing the files.
4. Run the program using the following command:
   python main.py
