
# IT Helpdesk Ticket Registration System

## Purpose of the Application
This application is a simple, modular Ticket Registration System for a university IT Support team. It allows students to report technical issues and automatically generates a helpdesk ticket. The system assigns a specific technician to the ticket based on the priority level of the issue before investigation begins.
